## 🔗 มาตรฐานการรวมโค้ดสำหรับสมาชิกในทีม (คู่มือหัวหน้าทีม นาย A)

เพื่อให้สมาชิกทุกคนนำหน้า Sub Web มารวมกับ `index.html` ได้อย่างสมบูรณ์:

1. **ดึงไฟล์ CSS หลักไปใช้ทุกหน้า:**
   ใส่ `<link rel="stylesheet" href="css/style.css" />` ใน `<head>` ของทุกไฟล์ เพื่อให้สี ฟอนต์ Header, Navbar และ Footer เหมือนกันทั้งเว็บไซต์
2. **คัดลอก `<header class="site-header">...</header>` และ `<footer class="site-footer">...</footer>`** จาก `index.html` ไปวางครอบเนื้อหา `<main>` ของแต่ละ Sub Web (เปลี่ยนคลาส `active` บนเมนู `.nav-link` ให้ตรงกับหน้าของตนเอง)
3. **การเชื่อมข้อมูลข้ามหน้าด้วย `localStorage`:**
   - **`eggify_products`**: เก็บรายการสินค้าทั้งหมด (หน้า `products.html` และ `admin.html` สามารถอ่าน/เพิ่ม/ลบ/แก้ไขข้อมูลชุดนี้ร่วมกับหน้าแรกได้ทันที)
   - **`eggify_cart`**: เก็บรายการสินค้าในตะกร้า (เมื่อลูกค้ากด `+ ใส่ตะกร้า` จากหน้า `index.html` ข้อมูลจะส่งต่อไปยังหน้า `cart.html` โดยอัตโนมัติ)
   - **`eggify_active_coupon`**: เก็บโค้ดคูปองส่วนลดที่ลูกค้ากดคัดลอกจากแบนเนอร์โปรโมชั่น (`EGGFRESH20`, `FREESHIP299`, `FAMILY50`)
