# 🥚 EGGIFY – Fresh Egg Market (ระบบขายไข่ออนไลน์ครบวงจร)

**แนวคิดการออกแบบ:** Minimal Edition ผสม Bento Grid UI ทันสมัย สะอาดตา ใช้งานง่าย รองรับทั้งการรันเป็นเว็บออนไลน์แบบ Full-Stack (Node.js + SQLite Database) และ Static Web Hosting (GitHub Pages / Netlify / Render)

---

| ผู้รับผิดชอบ | บทบาท / ระบบ | รายละเอียดงานที่ดำเนินการเสร็จสมบูรณ์ | ไฟล์ที่เกี่ยวข้อง |
| :--- | :--- | :--- | :--- |

## 🗄️ การรันเซิร์ฟเวอร์และฐานข้อมูลออนไลน์ (SQLite + Node.js)

โปรเจกต์นี้ออกแบบให้รองรับการรันเป็นเว็บออนไลน์ได้ 2 รูปแบบโดยอัตโนมัติ:

### 1. รันแบบ Full-Stack Server พร้อมฐานข้อมูล SQLite (`database/eggify.db`)
ดับเบิลคลิกไฟล์ `start-server.bat` หรือรันคำสั่งใน Terminal:
```bash
node server.js
```
จากนั้นเปิดเบราว์เซอร์ไปที่ `http://localhost:3000`
- ข้อมูลสินค้า (`products`), คำสั่งซื้อ (`orders`), รายการย่อย (`order_items`) และสมาชิก (`users`) จะถูกบันทึกลงฐานข้อมูล SQLite จริงที่ไฟล์ `database/eggify.db`

### 2. รันบน Static Hosting (เช่น GitHub Pages / Live Server)
สามารถเปิดไฟล์ `index.html` หรือนำขึ้น GitHub Pages ได้ทันที ระบบ `js/db.js` จะสลับไปใช้ฐานข้อมูล Cloud-Synced `localStorage` โดยอัตโนมัติ ทำให้ทุกฟีเจอร์ (ล็อกอิน, สมัครสมาชิก, เพิ่ม/ลบสินค้า, ตะกร้า, สั่งซื้อ, Admin) ทำงานได้ครบ 100%
